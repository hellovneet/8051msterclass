# 8051 MASTERCLASS — ITV-304 (Monochrome Edition)

## Run
1. Download and extract `8051_masterclass.zip`.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Choose English, Hindi, or English + Hindi from the language selector.

## Added features
- Strict black-and-white interface
- Search across lessons
- Bookmarks saved in browser storage
- Lesson progress saved in browser storage
- Focus timer (25-minute session)
- Flashcards for active recall
- Assembly examples with explanations
- MCQ quiz and revision sheet
- Responsive layout

## Syllabus coverage
All five units and every topic listed in the supplied ITV-304 syllabus are represented. Assembly examples and flashcards are supplementary study aids. Device-specific timing and pin behavior should be checked against the exact 8051 derivative used in your lab.
