8051 program examples

Add two 8-bit numbers

MOV A,#25H ; load first number
ADD A,#13H ; add second number
MOV 30H,A  ; store result
HERE: SJMP HERE

A becomes 38H. The result is stored at internal RAM address 30H.

Copy a byte using indirect addressing

MOV R0,#40H ; source address
MOV A,@R0   ; read source byte
INC R0      ; next address
MOV @R0,A   ; write destination
HERE: SJMP HERE

The byte at 40H is copied to 41H. This is an illustrative example.

Count down using DJNZ

MOV R2,#05H
LOOP: DJNZ R2,LOOP
HERE: SJMP HERE

DJNZ decrements R2 and branches while it is not zero.

BEFORE THE EXAM

Rapid revision sheet

8051 core facts

  • 8-bit microcontroller
  • 4 KB on-chip program ROM in classic 8051
  • 128 bytes internal RAM
  • 32 programmable I/O lines
  • Two 16-bit timers/counters
  • One full-duplex serial port

Remember these registers

  • TMOD – timer mode selection
  • TCON – timer and external interrupt control
  • SCON – serial port control
  • SBUF – serial data buffer
  • IE – interrupt enable
  • IP – interrupt priority

Exam answer framework

  • 2 marks: definition + one key point
  • 5 marks: definition, diagram/table, working and example
  • 10 marks: introduction, labelled diagram, detailed explanation, advantages/applications

Important distinctions

  • MOV: internal/register data transfer
  • MOVC: read code memory
  • MOVX: access external data memory
  • RET: return from subroutine
  • RETI: return from interrupt service routine
